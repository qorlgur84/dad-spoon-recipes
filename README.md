# 아빠숟가락 레시피 데이터

`아빠숟가락` 앱이 설치 파일을 다시 받지 않고도 레시피를 업데이트할 수 있게 하는 공개 데이터 저장소입니다.

현재 데이터 버전은 **2.6.0**이며 레시피 130개와 조리도구별 조리법 165개가 들어 있습니다.

## 앱에서 업데이트

앱의 왼쪽 메뉴를 열고 **레시피 업데이트**를 누르면 `manifest.json`의 버전을 확인합니다. 새 버전이면 `recipes.json`을 내려받고 SHA-256 검증 및 레시피 구조 검증을 통과한 뒤 휴대폰에 저장합니다. 즐겨찾기와 개인 메모는 GitHub으로 올라가지 않습니다.

## 레시피 추가 규칙

- 주재료나 완성 식감이 다르면 별도 레시피로 등록합니다.
- 재료별 기초 손질, 제외 가능 재료, 동일 손질·조리 시간의 대체 재료를 기록합니다.
- 모든 단계에 불 세기, 시간, 조리 과정, 완료 확인 기준을 기록합니다.
- 아빠숟가락 1은 15ml, 반은 7.5ml, 종이컵 1은 180ml이며 g·ml 환산값을 함께 저장합니다.
- 중식·일식·양식 등 해외 음식은 원형의 핵심 조리법을 유지하면서 한국 마트 재료, 한국 가정의 화력과 조리도구, 한국인 입맛에 맞게 재해석합니다.
- 해외 음식도 미원·다시다·연두를 허용하며 가능한 경우 국내 레시피 출처를 우선해 교차검증합니다.
- 신규 한식은 검색 목록이 아닌 국내 개별 레시피 주소를 최소 1개 포함해야 합니다.
- 검증일, HTTPS 조리 출처, 공식 식품 안전 출처를 포함합니다.

## 배포 절차

1. `recipes.json`을 수정하고 `version`과 `updatedAt`을 올립니다.
2. `npm run release`로 개수와 SHA-256가 든 `manifest.json`을 생성합니다.
3. `npm run validate`가 통과한 뒤만 GitHub에 올립니다.

검증이 실패하면 `manifest.json`과 `recipes.json`을 GitHub에 올리지 않습니다.
